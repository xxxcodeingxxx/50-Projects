## Required TMDB notice

This product uses the TMDB API but is not endorsed or certified by TMDB.

Include that notice prominently in the application's About or Credits section, together with an approved TMDB logo. The app itself must carry this attribution; a README alone does not fulfill the in-app requirement. Keep the TMDB logo less prominent than the app's primary branding and do not alter it outside TMDB's permitted usage.

- [TMDB](https://www.themoviedb.org/)
- [Official API FAQ and attribution requirements](https://developer.themoviedb.org/docs/faq)
- [Approved TMDB logos](https://www.themoviedb.org/about/logos-attribution)

The TMDB logo is not included. Download an approved asset from TMDB when implementing the app.
