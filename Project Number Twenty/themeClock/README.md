Atlas Clock is a browser clock designed around two ways to read the same local time. The analog dial shows hour, minute, and second hands, while the digital display gives you the time at a glance. The calendar line shows the weekday and full date.

## Clock face

| Display | What it shows |
| :--- | :--- |
| Analog dial | Hour, minute, and second hands |
| Digital readout | Hours, minutes, and seconds |
| Calendar | Weekday, month, day, and year |

## Open the clock

Once the clock page is in place, open `index.html` in a browser. The project is designed for plain HTML, CSS, and JavaScript, with no build step.

## Add the favicon

Place both favicon files beside `index.html` and add these lines inside the document’s `<head>`. The ICO contains 16, 32, 48, and 64 pixel versions.

```html
<link rel="icon" href="./favicon.ico" sizes="16x16 32x32 48x48 64x64">
<link rel="icon" href="./favicon.svg" type="image/svg+xml" sizes="any">
```
